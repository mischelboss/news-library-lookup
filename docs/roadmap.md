# Roadmap

This is a hobby project, so the plan is short and flexible. It lists what exists, what is likely next, and what is only an idea.

## Scope today

| Dimension | Supported |
| --- | --- |
| Library | VÖBB Genios |
| Publishers | Spiegel, Tagesspiegel |
| Pages | Homepages |
| Browsers | Firefox desktop 140 or later |

## Done

- **Core flow:** paid-card detection, queued searches in the signed-in Genios session, ranked title matching, icons that open Genios in a new tab.
- **Safer matching:** freshness guard with a second pass for older articles, ambiguity handling, failure categories without sensitive logging, retry after sign-in, and a failure cooldown.
- **Installable build:** stable extension ID, data-collection declaration, onboarding page, packaging checks, and a release guide ([releasing.md](releasing.md)).
- **Second publisher:** adapter registry in `extension/publishers.js` and a Tagesspiegel adapter, covered by simulated tests.

## Next

1. **Check Tagesspiegel against real Genios data.** The adapter is tested only with simulated responses. Still to confirm with a signed-in session: that the JSON endpoint accepts repeated `source=` parameters, the exact `QUELLENNAME` values, how titles are stored (with or without the kicker), and whether the `Tagesspiegel CHECKPOINT` source belongs in the list. See [testing.md](testing.md).
2. **Section and listing pages.** Today only homepages are processed. Plan: collect real markup examples, replace the homepage check with a per-adapter listing-path allowlist, keep article pages excluded, check scan cost on busy pages (the queue runs one request at a time), and add tests for near-miss paths.

## Ideas, not planned

- **Chrome:** needs a service-worker background that survives restarts (persisted queue and cooldown), a per-browser manifest generated by the packaging script, and a distribution route.
- **Firefox for Android and Safari (macOS and iOS):** the install route and cookie behavior are the open questions. Each would start as a short spike.
- **Article-page banner, options page, automatic re-check after sign-in, entitlement hints from verified response fields.**
- **More publishers or libraries.** Each needs its own adapter or integration, tests, and a look at the relevant terms of use. Open an issue first.

## Out of scope

- Bypassing paywalls or access controls in any way.
- Storing, copying, or republishing article text.
- Sharing sessions, caches, or credentials between users.
